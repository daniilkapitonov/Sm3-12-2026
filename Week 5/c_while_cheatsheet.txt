ШПАРГАЛКА ПО ТЕМЕ «ЦИКЛ WHILE В C»

1. Что такое while

Цикл while повторяет блок кода, пока условие истинно.

Синтаксис:

while (условие)
{
    действия;
}

Если условие сразу ложно, тело цикла не выполнится ни разу.


2. Простейший пример

int i = 1;

while (i <= 5)
{
    printf("%d\n", i);
    i++;
}

Результат:

1
2
3
4
5

После цикла i == 6.


3. Как выполняется цикл

int i = 1;

while (i <= 3)
{
    printf("%d ", i);
    i++;
}

Пошагово:

i = 1 -> условие истинно -> вывод 1 -> i = 2
i = 2 -> условие истинно -> вывод 2 -> i = 3
i = 3 -> условие истинно -> вывод 3 -> i = 4
i = 4 -> условие ложно -> цикл завершен


4. Счетчик цикла

Переменная i часто используется как счетчик.

int i = 1;

while (i <= 10)
{
    printf("%d ", i);
    i++;
}


5. Шаг может быть любым

int i = 2;

while (i <= 10)
{
    printf("%d ", i);
    i += 2;
}

Результат:

2 4 6 8 10


6. Цикл в обратную сторону

int i = 5;

while (i >= 1)
{
    printf("%d ", i);
    i--;
}

Результат:

5 4 3 2 1


7. Бесконечный цикл

Ошибка:

int i = 1;

while (i <= 5)
{
    printf("%d ", i);
}

i не изменяется, поэтому условие всегда истинно.

Правильно:

int i = 1;

while (i <= 5)
{
    printf("%d ", i);
    i++;
}


8. Накопитель

Накопитель нужен, когда результат собирается постепенно.

Пример: сумма чисел от 1 до n.

int n;
int i = 1;
int sum = 0;

scanf("%d", &n);

while (i <= n)
{
    sum += i;
    i++;
}

printf("%d\n", sum);

Для n = 4:

sum = 0
sum = 1
sum = 3
sum = 6
sum = 10


9. Счетчик событий

Пример: посчитать, сколько чисел от 1 до n делятся на 3.

int n;
int i = 1;
int count = 0;

scanf("%d", &n);

while (i <= n)
{
    if (i % 3 == 0)
    {
        count++;
    }

    i++;
}

printf("%d\n", count);

Здесь:
i — счетчик цикла
count — количество подходящих значений


10. if внутри while

Пример: вывести четные числа от 1 до 10.

int i = 1;

while (i <= 10)
{
    if (i % 2 == 0)
    {
        printf("%d ", i);
    }

    i++;
}

Результат:

2 4 6 8 10


11. Порядок действий важен

Вариант 1:

int i = 1;

while (i <= 5)
{
    printf("%d ", i);
    i++;
}

Результат:

1 2 3 4 5

Вариант 2:

int i = 1;

while (i <= 5)
{
    i++;
    printf("%d ", i);
}

Результат:

2 3 4 5 6


12. Изменение не обязательно на 1

int i = 1;

while (i < 20)
{
    printf("%d ", i);
    i = i * 2;
}

Результат:

1 2 4 8 16


13. Работа с цифрами числа

Последняя цифра:

n % 10

Удалить последнюю цифру:

n / 10

Пример:

1234 % 10 -> 4
1234 / 10 -> 123


14. Подсчет количества цифр

int n;
int count = 0;

scanf("%d", &n);

while (n > 0)
{
    n = n / 10;
    count++;
}

printf("%d\n", count);

Для 1234 результат:

4


15. Общая схема while

int i = начальное_значение;

while (условие)
{
    действия;
    изменение_переменной;
}

Перед написанием цикла нужно понимать:

1. С какого значения начинаем.
2. Пока какое условие выполняется цикл.
3. Что делаем на каждой итерации.
4. Как меняется переменная.
5. Когда условие станет ложным.


16. Частые ошибки

Ошибка 1. Переменная в условии не меняется.
Результат — бесконечный цикл.

Ошибка 2. Неверное начальное значение.

Ошибка 3. Перепутаны < и <=.

while (i < 5)

и

while (i <= 5)

дают разное количество итераций.

Ошибка 4. Накопитель не инициализирован.

Неправильно:

int sum;

Правильно:

int sum = 0;

Ошибка 5. Счетчик не инициализирован.

Неправильно:

int count;

Правильно:

int count = 0;


17. Что нужно помнить

1. while повторяет блок, пока условие истинно.
2. Условие проверяется до каждой итерации.
3. Тело цикла может не выполниться ни разу.
4. Переменная, влияющая на условие, обычно должна изменяться внутри цикла.
5. Если условие всегда истинно, получится бесконечный цикл.
6. Для суммы удобно использовать накопитель.
7. Для количества подходящих значений удобно использовать отдельный счетчик.
8. if можно использовать внутри while.
9. % 10 и / 10 полезны для работы с цифрами целого числа.
