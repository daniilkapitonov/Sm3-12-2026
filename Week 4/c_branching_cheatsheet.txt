ШПАРГАЛКА ПО ТЕМЕ «ВЕТВЛЕНИЯ В C»

1. Условие

Условие — это выражение, результат которого интерпретируется как истина или ложь.

В языке C:
0      — ложь
не 0   — истина

Примеры условий:

x > 0
x == 10
x != 5
x >= 10 && x <= 20
x % 2 == 0


2. Операции сравнения

>    больше
<    меньше
>=   больше или равно
<=   меньше или равно
==   равно
!=   не равно

Важно:
=    присваивание
==   сравнение

Пример:

x = 5;      // записать 5 в x
x == 5      // проверить, равно ли x числу 5


3. Логические операции

&&   И
||   ИЛИ
!    НЕ

Примеры:

x > 0 && x < 10
// x больше 0 И меньше 10

x < 0 || x > 100
// x меньше 0 ИЛИ больше 100

!(x == 0)
// x не равен 0


4. Конструкция if

Синтаксис:

if (условие)
{
    действия;
}

Пример:

if (x > 0)
{
    printf("Positive\n");
}

Блок выполняется только тогда, когда условие истинно.


5. Конструкция if ... else

Используется, когда есть два варианта.

if (условие)
{
    действия_1;
}
else
{
    действия_2;
}

Пример:

if (x % 2 == 0)
{
    printf("Even\n");
}
else
{
    printf("Odd\n");
}


6. Несколько вариантов: else if

if (условие_1)
{
    действия_1;
}
else if (условие_2)
{
    действия_2;
}
else
{
    действия_3;
}

Пример:

if (x > 0)
{
    printf("Positive\n");
}
else if (x < 0)
{
    printf("Negative\n");
}
else
{
    printf("Zero\n");
}

Условия проверяются сверху вниз.
После выполнения одной ветви остальные ветви этой цепочки не проверяются.


7. Два независимых if

if (x > 0)
{
    printf("A\n");
}

if (x > 10)
{
    printf("B\n");
}

Если x = 20, выполнятся оба блока.

Это не то же самое, что:

if (x > 0)
{
    printf("A\n");
}
else if (x > 10)
{
    printf("B\n");
}

Во втором случае при x = 20 выполнится только первый блок.


8. Проверка диапазона

Число x находится в диапазоне от 10 до 20 включительно:

x >= 10 && x <= 20

Число x находится вне диапазона:

x < 10 || x > 20

Не записывайте:

10 <= x <= 20

В C это выражение работает не так, как математическое двойное неравенство.


9. Проверка чётности

Чётное число:

x % 2 == 0

Нечётное число:

x % 2 != 0


10. Проверка делимости

Делится на 5:

x % 5 == 0

Делится одновременно на 3 и на 5:

x % 3 == 0 && x % 5 == 0

Делится на 3 или на 5:

x % 3 == 0 || x % 5 == 0


11. Фигурные скобки

Рекомендуемый вариант:

if (x > 0)
{
    printf("Positive\n");
}

Даже если внутри только одна инструкция, используйте { }.


12. Частые ошибки

Ошибка 1:

if (x = 5)

Здесь происходит присваивание.

Правильно:

if (x == 5)


Ошибка 2:

if (x > 0);
{
    printf("Positive\n");
}

Лишняя точка с запятой завершает if.

Правильно:

if (x > 0)
{
    printf("Positive\n");
}


Ошибка 3:

if (10 < x < 20)

Правильно:

if (x > 10 && x < 20)


13. Пример полной программы

#include <stdio.h>

int main(void)
{
    int x;

    scanf("%d", &x);

    if (x > 0)
    {
        printf("Positive\n");
    }
    else if (x < 0)
    {
        printf("Negative\n");
    }
    else
    {
        printf("Zero\n");
    }

    return 0;
}


14. Пример с несколькими условиями

#include <stdio.h>

int main(void)
{
    int x;

    scanf("%d", &x);

    if (x > 0 && x % 2 == 0)
    {
        printf("Positive even\n");
    }
    else if (x > 0 && x % 2 != 0)
    {
        printf("Positive odd\n");
    }
    else if (x < 0)
    {
        printf("Negative\n");
    }
    else
    {
        printf("Zero\n");
    }

    return 0;
}


15. Что нужно помнить

1. Условие в if вычисляется как истина или ложь.
2. 0 — ложь, любое ненулевое значение — истина.
3. = и == — разные операции.
4. && означает И, || означает ИЛИ, ! означает НЕ.
5. В цепочке if / else if / else выполняется только одна подходящая ветвь.
6. Несколько отдельных if проверяются независимо друг от друга.
7. Для диапазона нужно записывать обе границы явно:
   x >= a && x <= b
8. Для чётности и делимости удобно использовать %.
