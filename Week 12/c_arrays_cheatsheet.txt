ОДНОМЕРНЫЕ МАССИВЫ В C
Краткая шпаргалка

1. ЧТО ТАКОЕ МАССИВ

Массив — последовательность элементов одного типа, расположенных
в памяти подряд. К каждому элементу обращаются по индексу.

int a[5];        // массив из 5 элементов типа int

a[0] — первый элемент
a[1] — второй элемент
a[4] — пятый элемент

ВАЖНО: индексы массива из n элементов — от 0 до n - 1.
Обращение к a[n] выходит за границы массива.


2. ОБЪЯВЛЕНИЕ И ИНИЦИАЛИЗАЦИЯ

int a[5];                         // элементы не инициализированы
int b[5] = {10, 20, 30, 40, 50}; // все значения заданы
int c[5] = {10, 20};             // результат: 10 20 0 0 0
int d[5] = {0};                  // все элементы равны 0
int e[] = {3, 6, 9};             // размер определяется автоматически: 3

У локального массива без инициализации значения элементов
неизвестны. Перед чтением нужно записать значения.


3. ОБРАЩЕНИЕ К ЭЛЕМЕНТАМ

int a[3] = {2, 4, 6};

a[1] = 10;          // массив стал: 2 10 6
a[0] = a[1] + a[2]; // массив стал: 16 10 6

Элемент a[i] можно использовать как обычную переменную типа int.


4. ВВОД И ВЫВОД

#include <stdio.h>

int main(void)
{
    int a[5];

    for (int i = 0; i < 5; i++)
    {
        scanf("%d", &a[i]);
    }

    for (int i = 0; i < 5; i++)
    {
        printf("%d ", a[i]);
    }

    printf("\n");
    return 0;
}

&a[i] — адрес отдельного элемента; он необходим для scanf("%d", ...).


5. ВМЕСТИМОСТЬ МАССИВА И КОЛИЧЕСТВО ЭЛЕМЕНТОВ

int a[100]; // выделено место для 100 чисел
int n;      // фактически используемое количество элементов

scanf("%d", &n);

if (n < 1 || n > 100)
{
    return 1; // некорректное количество элементов
}

for (int i = 0; i < n; i++)
{
    scanf("%d", &a[i]);
}

Вместимость: 100. Используемые индексы: от 0 до n - 1.
Проверяйте n до ввода элементов.


6. СУММА ЭЛЕМЕНТОВ

int sum = 0;

for (int i = 0; i < n; i++)
{
    sum += a[i];
}

printf("%d\n", sum);

sum — накопитель. Перед циклом его нужно инициализировать.
Предполагается, что сумма помещается в int.


7. СРЕДНЕЕ АРИФМЕТИЧЕСКОЕ

После подсчёта суммы (при n > 0):

double average = (double)sum / n;
printf("%.2f\n", average);

(double)sum переводит деление в вещественное.
Если оба операнда целые, / выполняет целочисленное деление.


8. ПОДСЧЁТ ЭЛЕМЕНТОВ ПО УСЛОВИЮ

Пример: количество положительных элементов.

int count = 0;

for (int i = 0; i < n; i++)
{
    if (a[i] > 0)
    {
        count++;
    }
}

Другие условия:

a[i] < 0           // отрицательный элемент
a[i] % 2 == 0      // чётный элемент
a[i] % 5 == 0      // кратен 5
a[i] > 0 && a[i] % 2 == 0 // положительный и чётный


9. МАКСИМАЛЬНЫЙ ЭЛЕМЕНТ

При n > 0:

int max = a[0];

for (int i = 1; i < n; i++)
{
    if (a[i] > max)
    {
        max = a[i];
    }
}

printf("%d\n", max);

Начинаем с первого элемента, а не с 0: все элементы
могут быть отрицательными.


10. ИНДЕКС МАКСИМАЛЬНОГО ЭЛЕМЕНТА

При n > 0:

int indexMax = 0;

for (int i = 1; i < n; i++)
{
    if (a[i] > a[indexMax])
    {
        indexMax = i;
    }
}

printf("Index: %d\n", indexMax);
printf("Value: %d\n", a[indexMax]);

При > сохраняется первое вхождение максимума.
При >= сохраняется последнее вхождение максимума.


11. ПОИСК ПЕРВОГО ВХОЖДЕНИЯ

int target;
scanf("%d", &target);

int index = -1; // -1 означает «не найдено»

for (int i = 0; i < n; i++)
{
    if (a[i] == target)
    {
        index = i;
        break;
    }
}

printf("%d\n", index);

Если элемент найден, break прекращает поиск.
Если элемент отсутствует, index остаётся равным -1.


12. РАЗМЕР МАССИВА

int a[5] = {1, 2, 3, 4, 5};

printf("%zu\n", sizeof(a));

Количество элементов массива можно вычислить так:

size_t count = sizeof(a) / sizeof(a[0]);

Это работает для настоящего массива в текущей области видимости.
При передаче массива в функцию sizeof параметра не даст
количество элементов исходного массива.


13. ПРИМЕР ИЗМЕНЕНИЯ ЭЛЕМЕНТОВ В ЦИКЛЕ

int a[5] = {1, 2, 3, 4, 5};

for (int i = 0; i < 5; i++)
{
    a[i] += i;
}

// Результат: 1 3 5 7 9

Порядок обработки важен. Если очередной элемент вычисляется
через предыдущий, программа может использовать уже изменённое значение.


14. ТИПИЧНЫЕ ОШИБКИ

1) Выход за границу:
   int a[5];
   a[5] = 10;  // неверно: последний индекс — 4

2) Лишняя итерация:
   for (int i = 0; i <= n; i++) // неверно для массива из n элементов
   Правильно: i < n

3) Чтение неинициализированного элемента:
   int a[5];
   printf("%d", a[0]); // значение ещё не задано

4) Пропущен & при вводе:
   scanf("%d", a[i]);  // неверно
   scanf("%d", &a[i]); // верно

5) Не проверено количество элементов:
   int a[100];
   // при n > 100 запись выйдет за пределы массива

6) Неправильная инициализация максимума:
   int max = 0; // ошибочно, если все значения отрицательные
   int max = a[0]; // верно при n > 0

Выход за границы массива в C — неопределённое поведение.
Программа не обязана сообщать об этой ошибке.


15. ЧТО НАДО УМЕТЬ ПОСЛЕ ТЕМЫ

- Объявлять массив и задавать начальные значения.
- Обращаться к элементам по индексам от 0 до n - 1.
- Вводить и выводить массив с помощью for.
- Считать сумму, среднее и количество элементов по условию.
- Находить максимум и его индекс.
- Находить первое вхождение заданного значения.
- Не допускать выхода за границы массива.

Для первой темы массивов достаточно фиксированного размера.
Динамическая память и передача массивов в функции изучаются отдельно.
