ФУНКЦИИ В ЯЗЫКЕ C
Краткая шпаргалка

1. Зачем нужны функции

Функция — именованный блок кода, выполняющий определённую задачу.
Функции позволяют разбивать программу на части и повторно использовать код.

2. Общая форма

тип_результата имя(параметры)
{
    инструкции;
    return результат;
}

Пример:

int sum(int a, int b)
{
    return a + b;
}

sum — имя функции;
a, b — формальные параметры;
int перед sum — тип возвращаемого значения;
return — завершение функции с возвратом результата.

3. Вызов функции

int result = sum(5, 7);

Вызов sum(5, 7) возвращает 12. Значение записывается в result.

Функцию можно вызвать и внутри выражения:

printf("%d\n", sum(5, 7));

4. Объявление и определение

Объявление (прототип) сообщает компилятору имя, тип результата
и типы параметров функции:

int sum(int a, int b);

Определение содержит тело функции:

int sum(int a, int b)
{
    return a + b;
}

Если определение расположено после первого вызова, перед вызовом
нужно записать объявление.

5. Полная программа с функцией

#include <stdio.h>

int sum(int a, int b);

int main(void)
{
    int result = sum(5, 7);
    printf("%d\n", result);
    return 0;
}

int sum(int a, int b)
{
    return a + b;
}

Результат: 12

6. Параметры и аргументы

В определении:

int square(int x)
{
    return x * x;
}

x — формальный параметр.

В вызове:

square(8)

8 — фактический аргумент (значение, переданное при вызове).

Количество и порядок аргументов должны соответствовать объявлению.
Типы аргументов должны быть совместимы с типами параметров.

7. Передача по значению

В C параметры передаются по значению: функция получает копии значений.
Изменение параметра не изменяет исходную переменную.

#include <stdio.h>

void change(int x)
{
    x = 100;
}

int main(void)
{
    int a = 5;
    change(a);
    printf("%d\n", a);
    return 0;
}

Результат: 5

8. Возврат результата: return

int square(int x)
{
    return x * x;
}

return вычисляет значение, завершает работу функции и передаёт
результат вызывающему коду.

Вызов:

int y = square(4);  // y равно 16

Если функция объявлена с возвращаемым типом int, double и т. п.,
её результат должен соответствовать этому типу (или допускать
преобразование).

9. Функция без возвращаемого значения: void

void printHello(void)
{
    printf("Hello\n");
}

Вызов:

printHello();

void означает, что функция не возвращает значение.
(void) в списке параметров означает, что параметров нет.
В функции void допускается return; без значения, но он необязателен.

10. Функция с циклом

int sumToN(int n)
{
    int sum = 0;

    for (int i = 1; i <= n; i++)
    {
        sum += i;
    }

    return sum;
}

sumToN(4) возвращает 10.

11. Локальные переменные

Переменная, объявленная внутри блока { }, имеет блочную область видимости.
Обычно её имя доступно от объявления до конца этого блока.

int square(int x)
{
    int result = x * x;
    return result;
}

Переменная result недоступна по имени в main.
Параметр x также локален для функции square.

12. Глобальные переменные

Переменная, определённая вне функций, имеет область видимости файла
(с места объявления), если не вводятся дополнительные ограничения.

int counter = 0;

void addOne(void)
{
    counter++;
}

Такая функция зависит от внешнего состояния. По возможности
передавайте нужные значения параметрами, а результат возвращайте
через return.

13. Область видимости и одинаковые имена

int x = 100;

int main(void)
{
    int x = 5;
    printf("%d\n", x);
    return 0;
}

Результат: 5

Локальное имя x скрывает глобальное x внутри своего блока.

14. Частые ошибки

Ошибка: вызов функции до объявления.
Исправление: определить функцию выше вызова или добавить прототип.

Ошибка: забыть return в функции, которая должна вернуть значение.
Исправление: обеспечить возврат значения на всех допустимых путях.

Ошибка: считать, что изменение параметра меняет исходную переменную.
На самом деле при обычной передаче по значению меняется копия.

Ошибка: путать вывод на экран и возврат результата.
printf(...) выводит текст, а return передаёт значение вызывающему коду.

Ошибка: использовать локальную переменную за пределами её блока.

Ошибка: писать void main().
Для обычной консольной программы используйте int main(void).

15. Что запомнить

1) Функция выполняет отдельную задачу.
2) Объявление сообщает, как вызывать функцию; определение содержит код.
3) Параметры находятся в определении; аргументы — в вызове.
4) В C аргументы передаются по значению.
5) return возвращает результат и завершает функцию.
6) void означает отсутствие возвращаемого значения.
7) Локальная переменная недоступна за пределами своей области видимости.
8) Избегайте ненужной зависимости функций от глобальных переменных.
