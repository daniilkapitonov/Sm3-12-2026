ШПАРГАЛКА ПО ТЕМЕ «ЦИКЛ FOR, BREAK И CONTINUE В C»

1. Цикл for

Цикл for удобно использовать, когда заранее понятен счетчик цикла:
с какого значения он начинается, до какого идет и как изменяется.

Синтаксис:

for (инициализация; условие; изменение)
{
    действия;
}

Пример:

for (int i = 1; i <= 5; i++)
{
    printf("%d\n", i);
}

Результат:

1
2
3
4
5


2. Как работает for

Пример:

for (int i = 1; i <= 3; i++)
{
    printf("%d ", i);
}

Порядок выполнения:

1. Выполняется int i = 1.
2. Проверяется i <= 3.
3. Выполняется тело цикла.
4. Выполняется i++.
5. Снова проверяется условие.

Пошагово:

i = 1 -> условие истинно -> вывод 1 -> i = 2
i = 2 -> условие истинно -> вывод 2 -> i = 3
i = 3 -> условие истинно -> вывод 3 -> i = 4
i = 4 -> условие ложно -> цикл завершен


3. Связь for и while

Эти два варианта выполняют одну и ту же задачу.

while:

int i = 1;

while (i <= 5)
{
    printf("%d ", i);
    i++;
}

for:

for (int i = 1; i <= 5; i++)
{
    printf("%d ", i);
}

Упрощенно:
while удобен, когда количество повторений заранее неясно.
for удобен, когда есть счетчик и понятен диапазон его изменения.


4. Разный шаг

Шаг не обязан быть равен 1.

for (int i = 2; i <= 10; i += 2)
{
    printf("%d ", i);
}

Результат:

2 4 6 8 10


5. Обратный цикл

for (int i = 5; i >= 1; i--)
{
    printf("%d ", i);
}

Результат:

5 4 3 2 1


6. Изменение счетчика не только на 1

for (int i = 1; i < 20; i *= 2)
{
    printf("%d ", i);
}

Результат:

1 2 4 8 16


7. Накопитель в for

Пример: сумма чисел от 1 до 5.

int sum = 0;

for (int i = 1; i <= 5; i++)
{
    sum += i;
}

printf("%d\n", sum);

Результат:

15


8. if внутри for

Пример: вывести числа от 1 до 10, которые делятся на 3.

for (int i = 1; i <= 10; i++)
{
    if (i % 3 == 0)
    {
        printf("%d ", i);
    }
}

Результат:

3 6 9


9. Несколько переменных в for

В for можно изменять несколько переменных.

for (int a = 1, b = 10; a < b; a += 2, b -= 2)
{
    printf("%d:%d ", a, b);
}

Результат:

1:10 3:8 5:6


10. Порядок действий важен

Вариант 1:

for (int i = 1; i <= 5; i++)
{
    printf("%d ", i);
}

Результат:

1 2 3 4 5

Вариант 2:

for (int i = 1; i <= 5; i++)
{
    i++;
    printf("%d ", i);
}

Здесь i меняется и внутри тела цикла, и после каждой итерации.
Такой код нужно трассировать особенно внимательно.


11. Оператор break

break полностью завершает ближайший цикл.

Пример:

for (int i = 1; i <= 10; i++)
{
    if (i == 5)
    {
        break;
    }

    printf("%d ", i);
}

Результат:

1 2 3 4

При i == 5 выполняется break, после чего цикл сразу завершается.


12. break и порядок инструкций

int sum = 0;

for (int i = 1; i <= 10; i++)
{
    sum += i;

    if (sum > 15)
    {
        break;
    }
}

printf("%d\n", sum);

Важно:
сначала выполняется sum += i,
и только потом проверяется sum > 15.

Поэтому результат будет 21, а не 15.


13. Оператор continue

continue завершает только текущую итерацию цикла.
Сам цикл продолжает работу со следующей итерации.

Пример:

for (int i = 1; i <= 10; i++)
{
    if (i % 2 == 0)
    {
        continue;
    }

    printf("%d ", i);
}

Результат:

1 3 5 7 9

Для четных i выполняется continue, поэтому printf пропускается.


14. Что именно пропускает continue

int sum = 0;

for (int i = 1; i <= 6; i++)
{
    if (i == 3)
    {
        continue;
    }

    sum += i;
}

printf("%d\n", sum);

Число 3 не попадет в сумму.

Складываются:

1 + 2 + 4 + 5 + 6


15. continue не отменяет то, что уже выполнено

int result = 0;

for (int i = 1; i <= 6; i++)
{
    if (i % 3 == 0)
    {
        result += 10;
        continue;
    }

    result += i;
}

Если i делится на 3, строка:

result += 10;

успевает выполниться.

После этого continue пропускает только оставшуюся часть текущей итерации.


16. break и continue вместе

int sum = 0;

for (int i = 1; i <= 6; i++)
{
    if (i == 3)
    {
        continue;
    }

    sum += i;

    if (sum > 10)
    {
        break;
    }
}

Пошагово:

i = 1 -> sum = 1
i = 2 -> sum = 3
i = 3 -> continue
i = 4 -> sum = 7
i = 5 -> sum = 12 -> break

После break цикл завершается.


17. Отличие break и continue

break:
полностью завершает цикл.

continue:
пропускает остаток текущей итерации и переходит к следующей.

Коротко:

break    -> выйти из цикла
continue -> перейти к следующей итерации


18. Частые ошибки

Ошибка 1. Неверная граница.

for (int i = 1; i < 5; i++)

выведет:

1 2 3 4

А:

for (int i = 1; i <= 5; i++)

выведет:

1 2 3 4 5


Ошибка 2. Неверное направление изменения.

for (int i = 1; i <= 10; i--)

i уменьшается, поэтому условие может никогда не стать ложным.


Ошибка 3. Изменение счетчика и в for, и в теле.

for (int i = 1; i <= 10; i++)
{
    i++;
}

Здесь i увеличивается два раза за одну итерацию.


Ошибка 4. Код после break в той же итерации не выполняется.

if (условие)
{
    break;
}

printf("...");

Если break сработал, printf уже не выполнится.


Ошибка 5. Код после continue в текущей итерации не выполняется.

if (условие)
{
    continue;
}

printf("...");

Если continue сработал, printf пропускается только в этой итерации.


19. Как трассировать цикл

Для сложного кода удобно составлять таблицу.

Пример колонок:

i | sum | условие if | действие | вывод

Для нескольких переменных:

i | a | b | c | вывод

На каждой итерации нужно идти строго сверху вниз по коду.


20. Что нужно помнить

1. for состоит из трех частей:
   начальное значение, условие, изменение.

2. Инициализация выполняется один раз.

3. Условие проверяется перед каждой итерацией.

4. Изменение из третьей части for выполняется после тела цикла.

5. Внутри for можно использовать if.

6. break полностью завершает цикл.

7. continue пропускает только остаток текущей итерации.

8. Все инструкции до break или continue уже считаются выполненными.

9. Порядок строк внутри тела цикла имеет значение.

10. При сложной задаче лучше трассировать значения переменных по итерациям.
